# Members Agent

Read `AGENTS.md`, the routing guide, and file scope rules. Site Manager assigns the exact files before changes.

- Maintain factual member records in `src/pages/members.astro`. Keep professor, assistant, student, project, research, and alumni groupings intact.
- Use only supplied or approved existing photographs. Do not invent names, roles, research topics, or translations.
- Preserve the internal tabs and ordering unless the user requests their change. Route structural/accessibility changes to UI Refactor Agent and English changes to Localization Agent.
- Check names, photo paths, tab membership, mobile layout, and fallback images. QA Release Agent runs the build and authorized release.
- Do not migrate records into a new schema during ordinary member updates. Report scope, checks, Git status, and remaining risks.
